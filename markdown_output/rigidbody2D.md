# Rigidbody 2D

Rigidbodies enable physics-based behavior, such as reactions to gravity, mass, drag, and momentum. A **Rigidbody** 2D is a 2D component you can use to enable an object to act under the control of physics.

**Topic** | **Description**  
---|---  
**Introduction to Rigidbody 2D** | Learn how to use Rigidbody 2D in your project and how they interact with **Collider** 2D components.  
**Rigidbody 2D body types** | Choose which **Body Type** to use to define the behavior of the Rigidbody 2D.  
**Simulated property** | Use this property to start or stop a Rigidbody 2D and any attached Collider 2Ds and **Joint** 2Ds from interacting with the 2D physics simulation.
