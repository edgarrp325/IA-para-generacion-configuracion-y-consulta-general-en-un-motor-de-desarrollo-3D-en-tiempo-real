# ContentNamespaces

A ContentNamespace can help you to organize content into separate categories.

You can use the default ContentNamespace or create your own custom namespace with the ContentNamespace.GetOrCreateNamespace function.

**Note:** A ContentNamespace name must contain only alphanumeric characters and can’t be longer than 16 characters.

APIs that use ContentNamespaces:

  * Archives
