# Collider types

Colliders in Unity have different **collider** types depending on whether they have an associated **Rigidbody** types depending on whether they have an associated **Rigidbody** , and how that Rigidbody is configured. A Collider’s type defines how it interacts with other colliders, and how it responds to simulated physics forces.
