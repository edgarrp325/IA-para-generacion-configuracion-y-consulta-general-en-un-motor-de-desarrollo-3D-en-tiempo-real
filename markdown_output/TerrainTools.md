# Terrain Tools package

The Terrain Tools package provides additional functionality on top of Unity’s built-in Terrain tools. It includes more advanced features such as erosion tools, sculpting tools, and brush mask filters. It also contains the **Terrain**

This add-on toolset is suitable if you require more control over the appearance of your Terrain, and wish to streamline Terrain workflows. It’s also useful when you want to make more complex-looking Terrain, or author Terrain Texture data in external tools such as Houdini and World Machine.

For more information about how to install and use the Terrain Tools package, see the Terrain Tools package documentation.
