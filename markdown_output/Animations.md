# Legacy Animation system

Unity’s Legacy Animation system is a simpler alternative to Unity’s animation system.

## Working with Legacy Animations

To import a Legacy Animation, first select **Legacy** as the **Animation Type** in the Rig tab of the Import Settings window:

Rig tab on the Import Settings window

Make sure you enable the **Import Animation** option on the Animation tab.
