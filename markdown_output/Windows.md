# Windows

Unity provides support for developing games on the Windows platform. For information on getting started with Windows, refer to the following sections:

**Page** | **Description**  
---|---  
**Requirements and compatibility** | Know the supported versions and compatibility information before you start developing for Windows.  
**Integrating Unity into Windows and UWP applications** | Describes how to integrate the Unity Runtime Library into Windows.  
**Windows Player settings** | Details the player settings to configure your built Windows platform application. For a description of the general Player Settings, refer to Player Settings.  
**Develop for Windows** | Contains Windows specific development information.  
**Windows Build Settings** | Reference documentation on build settings for Windows.
