# USS custom properties (variables)

USS variables, also called custom properties, define values that you can reuse in other USS rules. You can create variables for any type of USS property.

**Topic** | **Description**  
---|---  
Create USS variables | Learn how to create, use, and specify default values for USS variables.  
Introduction to USS built-in variables | Understand built-in USS variables and how to specify default values for Editor and runtime **UI**.  
USS built-in variable reference | Reference of all the USS built-in variables and their default values.  
Get custom styles in C# scripts | Understand how to get the value of a custom style property applied to an element.
