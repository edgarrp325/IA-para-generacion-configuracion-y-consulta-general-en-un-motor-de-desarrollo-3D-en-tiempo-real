# Mesh components

This section contains information on components for working with meshes.

**Page** | **Description**  
---|---  
Mesh Renderer component | Information about the **Mesh** Renderer component, which renders regular meshes.  
Skinned Mesh Renderer component | Information about the Skinned **Mesh Renderer** component, which renders deformable meshes.  
Mesh Filter component | Information about the **Mesh Filter** component, which provides a reference to a mesh asset.  
Text Mesh component (legacy) | Information about the legacy **Text Mesh** component, which generates meshes to display strings of text.
