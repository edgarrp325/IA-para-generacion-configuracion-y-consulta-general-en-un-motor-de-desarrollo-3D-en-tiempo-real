# Visual Effect Graph Asset

A Visual Effect Graph Asset contains all of the necessary data, such as the graph and **shaders** , that Unity requires to process an effect

This Asset only works when you install the Visual Effect Graph package. For information on how to install the Visual Effect Graph, see the packages documentation.

For information on how to use Visual Effect Graph Assets, see the Visual Effect Graph package documentation.
