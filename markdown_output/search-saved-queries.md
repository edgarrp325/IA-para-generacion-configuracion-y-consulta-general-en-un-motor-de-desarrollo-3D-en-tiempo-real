# Search saved queries

The Saved Queries Search Provider searches all saved queries.

**NOTE:** This search requires a search token to execute it. You cannot make it an active Search Provider, or combine it with other Search Providers.

**Search token:** `q:`

**Default action:** Select the saved query.

**Context menu actions:**

Action: | Function:  
---|---  
**Select** | Selects the saved query in the **Project** window.  
**Exec** | Executes the search.
