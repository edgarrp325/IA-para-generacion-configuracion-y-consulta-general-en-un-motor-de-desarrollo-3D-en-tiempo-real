# Overview

Unity supports **XR** development on multiple platforms and devices through its XR **plug-in** development on multiple platforms and devices through its XR **plug-in** framework. In addition, Unity provides a set of packages that add features and developer tools for building XR games and applications. This section provides an overview of the supported platforms and describes the software architecture behind the XR plug-in framework.

Topic | Description  
---|---  
XR packages | Plug-ins and other packages that support XR development.  
AR overview | Get started with **augmented reality** development in Unity.  
VR and MR overview | Get started with **virtual reality** and **mixed reality** development in Unity.  
XR architecture | Describes the XR plug-in framework.  
XR API reference | Understand the common APIs for XR development that Unity provides.  
  
Refer to Project set up for instructions on how to add XR plug-ins to your project using the **XR Plug-in Management** system.
