# Search Settings and Preferences

Use the Settings Search Provider to search all of the settings in the Project Settings and Preferences windows. It returns all Settings and Preferences pages that match the search query.

**Search token:** `set:`

**Default action:** Opens the page in the Project Settings or Preferences window.

**Context menu actions:**

Action: | Function:  
---|---  
**Open** | Opens the page in the Project Settings or Preferences window.
